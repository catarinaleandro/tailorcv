# No-fabrication policy

A CV bullet is judged against the profile entries it cites.

| Label | Meaning | Example |
|---|---|---|
| SUPPORTED | Every fact, number and scope claim appears in the cited entry | Entry: "Built churn dashboard used by 3 teams". Bullet: "Built a churn dashboard used by 3 teams." |
| OVERSTATED | Same topic but claims more than the entry (bigger scope, stronger verb, extra outcome) | Bullet: "Led analytics for the company." Entry says the user contributed to one dashboard. |
| UNSUPPORTED | Fact, tool, number, title, date or employer not in any cited entry, or no cited entry | Bullet mentions SQL but no entry does. |

Allowed rewording: reordering, tightening, using the posting's terminology for the same thing, merging two entries that clearly describe one achievement (cite both IDs).
Not allowed: new metrics, new tools, stronger verbs than the evidence supports, implied team leadership, rounding up numbers.
When in doubt, label OVERSTATED and quote the exact gap.
