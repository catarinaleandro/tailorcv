# ATS-safe formatting and keyword rules

These are practical conventions, not guarantees. Real ATS behavior varies and is opaque. Never promise a pass.

## Layout (checkable by script)
1. Single column. No tables, text boxes, headers/footers holding content, or images of text.
2. Standard section headings: Summary, Experience, Education, Projects, Skills, Languages.
3. Standard fonts (Arial, Calibri, Times New Roman, Georgia), body size 10 to 12 pt.
4. Dates in one consistent format (for example Jun 2024 to Sep 2024).
5. Bullets use the template's built-in list style, not typed symbols.
6. Contact details in the body, not in a header.
7. Length: one page for under 10 years experience, otherwise two.

## Keywords
1. Use the posting's exact terms only where they are true for the user.
2. Spell out an acronym once, then use it (for example Search Engine Optimization (SEO)).
3. Place the most relevant keywords in the Summary, the first bullets of recent roles, and Skills.
4. Do not repeat a keyword unnaturally. A CV that echoes the posting everywhere reads as generic.
5. Do not add hidden text or white text. Never.

## Selection and order
- Lead each role with the bullets that match must-haves.
- Drop bullets that match nothing in the posting if space is tight.
- Reorder sections only if the template allows it.
