# Write-up template (2-3 pages)

| Section | Length | Contents |
|---|---|---|
| 1. Problem and user | 0.4 page | Who applies, job to be done, interview evidence, metric tree |
| 2. Approach | 0.6 page | Architecture diagram, pipeline, three design choices: structured profile, gap questions, independent auditor |
| 3. How I used Claude | 0.5 page | Skill, subagents, docx skill, Claude Code, API harness, notebook. What Claude did vs. what I decided. |
| 4. Results | 0.8 page | Condition table, 2-3 charts, human ratings, one before/after example, one failure and what it taught |
| 5. Limits and honest claims | 0.4 page | Small test set, one author, opaque ATS, proxy metrics, auditor can miss subtle embellishment, no interview-outcome claim |
| 6. Reproduce it | 0.2 page | Setup steps, sample persona, run time and cost |

Add: product trade-offs and cuts (web app, auto-apply, interview prep, MCP server) and next steps.
Tip: state every prompt change made after seeing results.
